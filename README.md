# 長生閒記

一款AI製作的放置修仙網頁遊戲，有一點點劇情。打開網頁就能玩，不用安裝。

## 網址
https://ycy2679.github.io/changsheng/

## 玩法
- **修煉**：每一世從凡人開始，入道後選法修、體修或魂修。線上 60 秒是遊戲裡 1 年，離線也會繼續修煉。
- **境界**：練氣到渡劫共 9 個大境界，突破成功決定品質，失敗會折壽。渡劫圓滿、道心夠深就能引動天雷飛升。
- **仙界**：撐過九道天雷就飛升仙界，從人仙一路修到玄仙。每個大境界都要渡仙劫，壽元將盡時會出現天人五衰；一身術法化成一招（大道至簡），還有本命法寶、仙籍差事和仙界秘境。飛升過一次後，轉世可以直接從仙人開始。
- **遊歷與閉關**：遊歷會遇到事件、戰鬥和寶物；閉關修煉較快，偶爾頓悟。
- **功法、術法、法寶、神通**：上百種可以收集、搭配和祭煉，用不到的可以參悟或賣掉。
- **宗門、秘境、坊市**：拜入宗門領俸祿、做任務；秘境打頭目拿寶物；坊市買賣丹藥和寶物。
- **百藝**：煉丹、煉器、佈陣，自己做丹藥和法寶。
- **輪迴**：壽元用盡就轉世，用道果點悟道樹，讓之後的每一世越來越快，也能讓化身自動處理雜事。
- **劇情**：上百個遊歷事件，還有 10 位重要人物的故事，散落在不同的輪迴裡。

## 存檔
存檔會存在瀏覽器裡，清除瀏覽器資料的話存檔就會不見。換裝置或清除資料前，可以在開始介面的「存檔匯出／匯入」把存檔匯出成一串文字保存，之後再貼回來匯入。
