# 長生閒記

一款AI製作的放置修仙網頁遊戲，有一點點劇情。打開網頁就能玩，不用安裝。

## 網址
https://ycy2679.github.io/changsheng/

## 玩法
- **修煉**：在線時修為會持續增長，現實 2 分鐘等於遊戲裡 1 年。離線時修為一樣會累積，而且不會增加年歲。
- **境界**：從練氣到渡劫，總共 9 個大境界、33 個小境界。每個大境界都有自己的修為丹和突破丹。
- **遊歷與閉關**：遊歷可以觸發奇遇、戰鬥、拿到寶物。閉關會累積根基，提高突破的成功率，偶爾還會頓悟。
- **功法、武技、法寶**：60 多部功法，分主修和輔修。90 種武技，有不同屬性的相剋。22 件法寶，可以祭煉。
- **坊市**：貨架定時刷新，偶爾會有特價的奇貨。
- **輪迴**：每一世開始時抽靈根和體質。壽元用盡會坐化，坐化後得到道果，可以用來點悟道樹上的天賦。
- **劇情**：60 個遊歷事件，還有 6 位重要人物的故事線。你在這一世的選擇，會在之後的某一世以「前世羈絆」找上你。

## 存檔
存檔會存在瀏覽器裡，清除瀏覽器資料的話存檔就會不見。
