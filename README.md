## 玩法
- **凡人篇**：每一世都從凡人開始。先抽出身，做些凡人的事累積底子，等仙緣上門後選一條路，測出靈根和體質、感氣入體，才算踏入仙途。
- **修煉**：在線時修為會持續增長，現實 2 分鐘等於遊戲裡 1 年。離線時修為一樣會累積，而且不會增加年歲。
- **境界**：從練氣到渡劫，總共 9 個大境界、33 個小境界。每個大境界都有自己的修為丹和突破丹。大境界突破失敗會折損壽元，還可能跌回上一個小境界；成功時會決定品質（例如無瑕道基、九竅金丹），品質越好這一世越強，也可以選擇「全力一搏」賭更好的品質。想要極品，還得先找到對應境界的天材地寶。
- **遊歷與閉關**：遊歷可以觸發奇遇、戰鬥、拿到寶物。每場戰鬥從目前的氣血、法力開始打，連戰會越打越虛，休息一下就會回滿。閉關會累積根基，提高突破的成功率，偶爾還會頓悟。
- **功法、術法、法寶**：130 多部功法，分主修和輔修，換主修要散功；後期點了「兩儀同修」還能多修一部副主修，兩部都圓滿後可以融合成自創功法。210 種術法，包括攻擊、護盾、回復、增益、回法等，有不同屬性的相剋，施放要耗法力，法力不夠時會自動服回氣丹。40 件法寶，可以祭煉，飾品最多能戴三件，高階法寶要到一定境界才驅使得動。
- **靈根**：天靈根、變異靈根、空靈根到後期各有專精路線；雜靈根前期較慢，但可以煉化五行之精補齊五行，踏入化神後成就「五行圓滿」反超。
- **神通**：54 門神通，分攻伐、法相、領域、禁錮、分身、不滅、遁法、機緣等，其中 33 門是天階功法專屬。踏入化神會依靈根覺醒本命神通；突破出極品、稀有體質、天階法寶祭煉圓滿也會覺醒；每部天階功法練到圓滿，還會覺醒它專屬的神通。
- **坊市**：貨架分功法、術法、法寶、丹藥四類，定時刷新，偶爾會有特價的奇貨。丹藥除了修為丹、突破丹，還有聚靈、狂血、破障、護脈、駐顏等二十多種，有的是限時藥效。用不到的丹藥和法寶可以照原價七成賣掉。
- **輪迴**：壽元用盡會坐化，坐化後得到道果，可以用來點悟道樹上的天賦，例如讓化身自動處理突破、服丹、事件選擇等雜事，或加快時間流速。歷世見過的功法、術法、法寶、神通、體質、靈根、事件和人物結局都會記進「輪迴錄」，收錄越多道果越多。
- **劇情**：60 個遊歷事件，還有 6 位重要人物的故事線。你在這一世的選擇，會在之後的某一世以「前世羈絆」找上你。
