# 長生閒記

一款AI製作的放置修仙網頁遊戲，有一點點劇情。打開網頁就能玩，不用安裝。

## 網址
https://ycy2679.github.io/changsheng/

## 玩法
- **凡人篇**：每一世都從凡人開始。先抽出身，做些凡人的事累積底子，等仙緣上門後選一條路，測出靈根和體質、感氣入體，才算踏入仙途。
- **修煉**：在線時修為會持續增長，現實 2 分鐘等於遊戲裡 1 年。離線時修為一樣會累積，而且不會增加年歲。
- **境界**：從練氣到渡劫，總共 9 個大境界、33 個小境界。每個大境界都有自己的修為丹和突破丹。大境界突破失敗會折損壽元，還可能跌回上一個小境界；成功時會決定品質（例如無瑕道基、九竅金丹），品質越好這一世越強，也可以選擇「全力一搏」賭更好的品質。
- **遊歷與閉關**：遊歷可以觸發奇遇、戰鬥、拿到寶物。每場戰鬥從目前的氣血、法力開始打，連戰會越打越虛，休息一下就會回滿。閉關會累積根基，提高突破的成功率，偶爾還會頓悟。
- **功法、術法、法寶**：60 多部功法，分主修和輔修，換主修要散功。100 種術法，包括攻擊、護盾、回復、增益、回法等，有不同屬性的相剋，施放要耗法力，法力不夠時會自動服回氣丹。22 件法寶，可以祭煉，高階法寶要到一定境界才驅使得動。
- **神通**：21 門神通，分攻伐、法相、領域、禁錮、分身、不滅、遁法等。踏入化神會依靈根覺醒本命神通；突破出極品、稀有體質、功法圓滿、天階法寶祭煉圓滿也會覺醒。
- **坊市**：貨架定時刷新，偶爾會有特價的奇貨。用不到的丹藥和法寶可以照原價七成賣掉。
- **輪迴**：壽元用盡會坐化，坐化後得到道果，可以用來點悟道樹上的天賦，例如讓化身自動處理突破、服丹、事件選擇等雜事，或加快時間流速。
- **劇情**：60 個遊歷事件，還有 6 位重要人物的故事線。你在這一世的選擇，會在之後的某一世以「前世羈絆」找上你。

## 存檔
存檔會存在瀏覽器裡，清除瀏覽器資料的話存檔就會不見。換裝置或清除資料前，可以在開始介面的「存檔匯出／匯入」把存檔匯出成一串文字保存，之後再貼回來匯入。
